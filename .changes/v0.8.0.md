## v0.8.0 - 2026-11-12
### Added
* Per-call options on Execute, ExecuteStream and WithTransformer - WithCallTimeout, WithRetry, WithCallAccessMode, WithIncludeCounters, WithTxMetadata, WithMaxExecutionTime, WithBookmarks and WithNotificationsFilter
* Query counters - Response, EagerResult and StreamSummary expose Counters when WithIncludeCounters is set
* WithMaxNetworkRetry and WithMaxTransientRetry set the two retry kinds separately (WithMaxRetry still sets both), and RetryPolicy overrides them per call
### Changed
* QueryService.Execute and ExecuteStream gain a variadic opts ...CallOption parameter, which breaks custom implementations of the interface; calls are unaffected. Statements containing IN TRANSACTIONS are no longer retried by default
### Fixed
* Expected query errors (Neo4j errors and HTTP API errors that the caller receives) are no longer logged at ERROR, and the request body is no longer copied to a string before sending
