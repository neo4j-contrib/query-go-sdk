## v0.7.0 - 2026-11-12
### Added
* WithMaxRetry now accepts 0, which disables retries; only negative values are rejected
* Retry statements that fail with a retryable Neo.TransientError.* (such as a deadlock) up to the WithMaxRetry count (default 3) with exponential backoff; Transaction.Terminated and Transaction.LockClientStopped are never retried, and WithMaxRetry(0) disables this. Streaming queries are retried only before the first record is delivered.
